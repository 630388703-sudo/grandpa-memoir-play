# 爷爷的时光

家庭回忆录小游戏的加密网页入口。打开网页并输入家人提供的密码。

这个发布包只包含入口页面、解密程序和加密内容，不包含原始照片、明文回忆或密码。原始项目单独保存。

内容使用 PBKDF2-SHA-256（600,000 次迭代）和 AES-256-GCM 加密。GitHub Pages 是静态托管，密码在访问者浏览器中用于解密，不会发送给服务器。

加密文件仍可被任何人下载并尝试猜测密码。因此短密码、日期密码无法提供强保密性；请只在明确接受这一限制时使用，并优先选择足够长且难猜的密码。已下载的旧加密版本不会因更换密码而失效。

公开此包前确认只有 `index.html`、`unlock.js`、`memoir.bin`、`README.md` 四个文件。不要上传原始项目、离线明文 HTML、照片目录或任何密码文件。

## GitHub Pages

将这四个文件放在一个全新的仓库根目录，再在 Settings → Pages 中选择 Deploy from a branch、main、/(root) 并保存。请勿把原来包含家庭资料的私有仓库直接改为公开。
